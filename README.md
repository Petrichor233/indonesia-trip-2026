# 行程助手生成器（只读分享）

这是一份给 Cursor 用的说明书（Skill）。  
**不是**印尼行程网站本身，也没有酒店、花费、同伴口令。

别人可以下载来用。  
**请不要改这个网页上的文件，也不要点「提议更改后合并到这里」。**  
你改自己电脑上的复印件即可。

---

## 发给朋友的用法（Windows）

1. 打开本页面后，点绿色按钮 **Code**，再点 **Download ZIP**。
2. 解压。里面有一个文件夹 `trip-assistant`。
3. 在自己电脑新建（没有就新建）：

   `C:\用户\你的用户名\.cursor\skills`

   不要放到 `skills-cursor` 里。
4. 把解压出来的整个 `trip-assistant` 文件夹放进去，最终是：

   `C:\用户\你的用户名\.cursor\skills\trip-assistant\SKILL.md`
5. 完全退出 Cursor，再打开。
6. 对 Cursor 说：做一个日本行程助手  
   或输入：`/trip-assistant`

Mac：放到 `用户名/.cursor/skills/trip-assistant`（访达按 Command + Shift + . 可显示隐藏文件夹）。
