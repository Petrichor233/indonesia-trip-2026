# 印尼双节旅行 · 2026.9.25–10.8

两人（WANG/QI、RAN/WEIJUN）14 天：科莫多海底奇境 · 巴厘岛文化海岛 · 泗水火山反穿。经胡志明、吉隆坡中转。

公开镜像（GitHub Pages）：https://petrichor233.github.io/indonesia-trip-2026/

手机或电脑打开即可。入口：今日、行程、地图、准备、备忘。

## 怎么用

- 航班、酒店、活动写死在 `index.html`，改完后推到 `Petrichor233/indonesia-trip-2026` 的 `main` 才会更新 Pages。
- 两人要一起勾选：打开「准备」→ 填写称呼和口令 → 创建共享 → 把带 `sid` 的链接发给对方。
- 朋友打开不带口令的链接只能看，不能改勾选和备忘。
- 不要把护照号、证件扫描写进备忘。
